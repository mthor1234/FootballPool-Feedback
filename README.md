# Football Squares Feedback

This public repository is the feedback and issue tracker for the Football Squares app. The application source repository remains private.

## Send feedback

- Report bugs, request features, or share general feedback.
- The app can open a prefilled issue draft using **Send feedback or report an issue**.
- Issues and comments are public, and submitting requires a GitHub account.
- Do not post display names, pool names, join codes, account IDs, or screenshots containing private information.

Nothing is submitted from the app until you review the draft, sign in to GitHub, and submit it.
